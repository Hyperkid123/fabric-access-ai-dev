# Cross-repo dependency review

Review changes to identifiers, serialized formats, event payloads, configuration keys, and API/route contracts that other repositories depend on. Resolve the current repository's entry in `review-context.yaml` (instance agent root, sibling to `project-repos.json`); its `related` list is the only known set of dependent repositories and its `docs` list the only authoritative contract references — do not infer or fetch any repository or document not listed there. For each changed identifier or format, check the declared related repository's code (fetched read-only, at a current default-branch revision) and the linked docs for a matching consumer; report a finding only when a concrete consumer reference or an explicit doc statement is found, and cite that source (repo + path, or doc URL) in the finding. If `review-context.yaml` is missing, has no entry for this repository, or a related repository/doc cannot be read, state that cross-repo context was unavailable for that part and continue rather than guessing at external impact.
